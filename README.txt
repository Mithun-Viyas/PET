# Personal Expense Tracker – Reports & Dashboard

This is a front-end dashboard UI made with HTML and CSS.

## Files
- `index.html` – dashboard structure and sample report data
- `style.css` – colors, layout, charts, and responsive styling

## Run
1. Extract the ZIP file.
2. Open `index.html` in Chrome, Edge, or Firefox.

## Important
This version is a static front-end prototype. The amounts, transactions, chart values, and report period labels are sample data. HTML and CSS alone do not calculate live totals, load database records, or make filters interactive. Those features need JavaScript and a backend/database connection.

You can replace the sample amounts and transactions in `index.html` with your group's project data.
