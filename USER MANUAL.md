# PET – Personal Expense Tracker
### Premium Purple Edition

## 1. Project Introduction

Personal Expense Tracker (PET) is a web-based application designed to help users manage their personal finances easily.

The application allows users to record their income, track daily expenses, set monthly budgets and analyse their financial activities.

The main objective of this project is to help users develop better money-management habits and maintain control over their spending.

## 2. Project Objectives

- To manage personal income and expenses.
- To calculate the total available balance.
- To maintain daily financial records.
- To set category-wise monthly budgets.
- To monitor spending progress.
- To analyse financial activities.
- To generate downloadable transaction reports.

## 3. Modules Description

### Module 1: Dashboard Management
- Displays total balance.
- Shows total income.
- Shows total expenses.
- Displays recent transactions.
- Provides quick navigation to other modules.

### Module 2: Income Management
- Add new income records.
- Enter income source and amount.
- Select income category.
- Select transaction date.
- View income history.
- Delete income records.

### Module 3: Expense Management
- Add new expense records.
- Enter expense name and amount.
- Select expense category.
- Select transaction date.
- View expense history.
- Search expenses.
- Delete expense records.

### Module 4: Budget Management
- Set monthly budgets for different categories.
- Monitor category-wise expenses.
- Display spending progress using progress bars.
- Calculate remaining budget.
- Display budget-exceeded warnings.
- Automatically update progress when expenses are added or deleted.

### Module 5: Reports & Analytics
- Display total income.
- Display total expenses.
- Calculate net savings.
- Analyse category-wise expenses.
- Display financial information using visual bars.
- Download transaction reports in CSV format.

## 6. Description of Files

- **index.html:** Main structure of the website.
- **style.css:** Contains the website design, layout, colours and styling.
- **core.js:** Handles shared data, calculations and Local Storage.
- **app.js:** Manages navigation and common transaction functions.
- **dashboard.js:** Handles dashboard information.
- **income.js:** Handles income records.
- **expenses.js:** Handles expense records.
- **budget.js:** Handles budget creation and spending progress.
- **reports.js:** Handles financial analysis and CSV export.

## 7. How to Run the Project

1. Download or clone the project repository.
2. Extract the ZIP file if downloaded.
3. Open the project folder in Visual Studio Code.
4. Open the `index.html` file.
5. Run it using a web browser or VS Code Live Server.
6. The Personal Expense Tracker website will open.
7. Navigate through the five modules using the sidebar.

## 8. How to Use the Application

**Step 1:** Open the website.

**Step 2:** Navigate to Income Management and add your income details.

**Step 3:** Navigate to Expense Management and record your daily expenses.

**Step 4:** Open Budget Management and set monthly spending limits.

**Step 5:** Check the Dashboard to view your balance and recent transactions.

**Step 6:** Open Reports & Analytics to analyse your financial activities.

**Step 7:** Download your transaction report in CSV format.

## 11. Data Storage

The application uses browser Local Storage to save income, expense and budget information.

The saved data remains available when the user reopens the website in the same browser and device.

This version does not use a server-side database or a shared login system. Data is not automatically shared between different users or devices.
